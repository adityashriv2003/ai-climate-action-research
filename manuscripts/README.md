# Manuscript files

This directory contains two alternative journal-formatted presentations of the same empirical study:

- `Applied_Energy_Manuscript.*`: single-column Applied Energy version.
- `IEEE_TSUSC_Short_Paper.*`: eight-page IEEE Transactions on Sustainable Computing short-paper version.
- `Applied_Energy_Highlights.docx`: required editable highlights file.
- `Applied_Energy_Declaration_of_Interest.docx`: separate funding and competing-interest declaration.

The two manuscript versions are alternatives and must not be submitted to different journals at the same time. The corresponding author is Aditya Shrivastava, Independent Researcher, `adityashrivastava2003@gmail.com`.

Before submission, the author must add the full postal affiliation requested by both venues, add an ORCID for IEEE, personally verify the complete analysis and citations, and approve the final manuscript. No persistent archive DOI is claimed because none has been created.
